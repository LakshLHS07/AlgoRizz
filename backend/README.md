# UDYAMA Welfare Scheme Matching API (FastAPI Backend)

Backend service for Semantic Welfare Scheme Discovery, Criteria Evaluation, e-KYC Verification, and CSC Operator Intake.

---

## Installation & Setup

1. **Install Python dependencies:**
   ```bash
   pip install -r backend/requirements.txt
   ```

2. **Run the FastAPI Server:**
   ```bash
   python backend/run.py
   ```
   *Runs on `http://127.0.0.1:7860` with hot-reloading.*

3. **Interactive Documentation:**
   - Swagger UI: [http://127.0.0.1:7860/docs](http://127.0.0.1:7860/docs)
   - ReDoc: [http://127.0.0.1:7860/redoc](http://127.0.0.1:7860/redoc)
